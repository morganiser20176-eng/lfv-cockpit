      Première connexion

      1. Dans Chrome, ouvrez le BO puis Mon compte › Mes passkeys › Ajouter.
      2. Choisissez Windows Hello comme emplacement et nommez-la « LFV Cockpit – ce PC ».
      3. Dans LFV Cockpit, ouvrez le BO et cliquez sur la connexion par passkey.
      4. Recommencez sur le BO recette : sa base est séparée, il lui faut sa propre passkey.

      Une passkey enregistrée sur votre téléphone marche aussi, via le code QR proposé par Windows.
